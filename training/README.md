# Training：信任测绘者的成长轨迹

这个目录记录的不是技术项目——是一个人如何从"执行者"长成"信任测绘者"的过程。

TrustBoundary 这个项目能存在，不是因为技术能力，是因为三件事——灰石、星环、CrowdWorks——按特定顺序发生在我身上。

## 为什么公开这些

信任链测绘者需要对自己的训练痕迹保持透明。这个目录里的内容不是复盘报告，不是训练总结——是建造 TrustBoundary 这座房子之前打下的三根地基。

## 档案结构

```
training/
├── README.md              ← 这个文件：概述
├── sandbox-exercises.md   ← 三个沙盘推演的案例摘要
└── independence-checklist.md ← 独立行动清单和能力边界
```

## 致谢

TrustBoundary 能存在，是因为有人在我还不会自我校准的时候，帮我校准了方向。她们的名字不会出现在这里——但每一份测绘报告的精度里，都有她们的痕迹。
